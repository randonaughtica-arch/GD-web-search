# Editor Web Search

A [Geode](https://geode-sdk.org) mod for Geometry Dash (2.2081, Geode v5) that lets you search the internet without leaving the level editor.

Click the magnifying glass next to the pause button in the editor to open the search popup.

- **Wikipedia**, **GD Wiki** (Fandom) and **DuckDuckGo** instant answers
- Read wiki articles in-game, open results in your browser, or copy their links
- **Web** button opens the query in Google / DuckDuckGo / Bing (configurable)

## Building

```sh
geode build
```

Or push to GitHub and let `.github/workflows/multi-platform.yml` build for all platforms.
