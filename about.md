# Editor Web Search

Look things up **without leaving the level editor**.

Click the <cg>magnifying glass</c> in the top-right of the editor to open the search popup.

## Sources
- **Wikipedia** – full-text article search, readable in-game
- **GD Wiki** – searches the Geometry Dash Fandom wiki (triggers, objects, levels...), readable in-game
- **DuckDuckGo** – instant answers and related links

Each result can be **read** inside the game (wiki sources), **opened** in your browser, or have its link **copied**.
The **Web** button opens your query in your browser's search engine for a full web search.

## Settings
- Default source
- Wikipedia language
- Results per search
- Browser search engine
